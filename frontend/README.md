# Frontend CodeTrack

React + Vite + Tailwind CSS. Ejecutar desde `frontend/`:

```sh
npm install
npm run dev
npm run lint
npm run build
```

La compilación del backend debe ejecutarse antes de la del frontend. Configuración local: ver `.env.example`.

## Estilos

Consultar la [guía de estilos](../docs/guia-estilos.md) para la paleta, componentes compartidos, medidas y validación responsive. El tema oscuro es fijo; los tokens y clases compartidas viven en `src/styles/index.css`. Todo texto de interfaz se mantiene en `src/locales/`.
